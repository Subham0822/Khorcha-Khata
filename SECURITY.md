# Security

## Reporting a vulnerability

If you discover a security issue, please **do not** open a public GitHub issue. Instead, report it privately to the repository maintainers (use GitHub [Security Advisories](https://github.com/Subham0822/Expensify-Zen/security/advisories/new) if enabled, or contact the owner through their profile).

## Credentials

- Never commit `.env.local` or real API keys. This repository ignores `.env*` files; use `.env.example` only as a template without secrets.
- If credentials were ever exposed, rotate them in the Firebase Console and OAuth apps immediately.
